Metro Chile para Linux — desarrollado por Javiera Navarrete.

Paquetes (dist/linux):
  · metro-chile-<v>-1.<fc>.x86_64.rpm   Fedora / RHEL / openSUSE:   sudo dnf install ./metro-chile-*.rpm
  · metro-chile_<v>-1_amd64.deb         Debian 13 / Ubuntu 24.04+:  sudo apt install ./metro-chile_*.deb
  · MetroChile-<v>-x86_64.AppImage     cualquier distro con GTK 4 y WebKitGTK 6: chmod +x y ejecutar
  · MetroChile-<v>.flatpak             flatpak install --user MetroChile-*.flatpak   (usa org.gnome.Platform 49 de Flathub)
  · metro-chile_<v>_amd64.snap          sudo snap install --dangerous metro-chile_*.snap (requiere gnome-46-2404)
Se instala en las rutas estándar: /usr/bin/metro-chile, /usr/share/metro-chile (interfaz), lanzador en
/usr/share/applications y ficha en /usr/share/metainfo. Comprobar integridad: sha256sum -c SHA256SUMS
